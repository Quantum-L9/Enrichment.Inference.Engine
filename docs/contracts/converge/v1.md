# Converge contract v1

**Action:** `converge` (TransportPacket, Gate-routed; EIE is the semantic owner).
**Producer:** IB-Odoo_19 `plasticos_gate/services/gate_builders.py::build_converge_request`.
**Consumer of the response:** IB-Odoo_19 `plasticos_gate/services/gate_mappers.py::map_converge_response`.
**Implementation:** `app/engines/handlers.py::handle_converge`, `app/engines/converge_contract.py`.
**Proof:** `tests/contracts/test_converge_contract_v1.py`.

This document specifies the eight-field partner request Odoo sends today. It
does not generalise that request to other schemas, domains or producers.

## Request

The payload is the canonical `EnrichRequest` (`app/models/schemas.py`), carried
untranslated.

| Field | Value Odoo sends | Rule |
|---|---|---|
| `entity` | partner snapshot; `id` and `_odoo_entity_id` both `res.partner:<n>` | `entity.id` is the identity. A body naming none is refused. |
| `object_type` | the domain, `plasticos` | Last fallback for domain resolution. |
| `objective` | `Full entity enrichment and inference` | Carried verbatim. |
| `max_variations` | 1..10 | Provider variations per pass. |
| `consensus_threshold` | 0.0..1.0 | Agreement bar. |
| `kb_context` | the domain, `plasticos` | Domain resolution: `domain_id`, `domain`, `kb_context`, `object_type`. |
| `schema` | `{name, website, city, zip, street, street2, email, phone}`, each `"string"` | The requested fields. These eight are the whole v1 field contract. |
| `idempotency_key` | one per logical operation (run + attempt) | Names the operation for replay. |
| `odoo` | Odoo context metadata | Not interpreted by EIE. |

`field_thresholds` is optional and unchanged by v1. The resolved domain's
effective spec revision is passed to the convergence loop as `domain_spec`,
from the same single read that supplies its hints and inference rules.

## Response

The payload is `EnrichResponse.model_dump()`. v1 fixes these rules:

1. **`fields` ⊆ `schema`.** Every key of `fields` is a key of the request's
   `schema`. Entity echo and inference-derived fields the request did not name
   are dropped before persistence, so the durable record equals the answer.
   The provenance blocks (`inferences`, `feature_vector`, `enrichment_payload`)
   are not field values and are not filtered.
2. **States.**

   | `state` | Meaning | `fields` | Persisted |
   |---|---|---|---|
   | `completed` | Converged and durable. `failure_reason` is null. | requested fields | yes |
   | `degraded` | The deadline stopped the request. `failure_reason` names it. | empty, or a partial subset of `schema` | no |
   | `failed` | Invalid request, every pass failed, or the result could not be made durable. | not a result | no |

   A partial result is never `completed`. Odoo maps any state other than
   `completed` to a non-ok status and does not inject it.
3. **25 s.** One deadline of 25 s (`CANONICAL_CONVERGE_BUDGET_SECONDS`) bounds
   the complete operation: validation, domain context, convergence, provider
   attempts, persistence and response assembly. A packet whose header carries a
   shorter `timeout_ms` lowers it; nothing raises it. On exhaustion the answer
   is `state="degraded"`, returned inside the budget.
4. **Replay.** A second request for the same logical operation (same tenant and
   `idempotency_key`) returns the same response apart from `processing_time_ms`
   and persists nothing further.

## Known limits

- EIE recomputes on replay; it does not serve a stored response. Identity of
  the replayed answer therefore holds for a deterministic provider and is
  proven only for that provider. Gate's idempotency cache, not EIE, is what
  returns a stored answer for a duplicate packet.
- A request without `schema` is outside v1; its `fields` are not filtered.
- The vendored consumer copy
  (`tests/contracts/fixtures/odoo_consumer/gate_mappers_vendored.py`) records
  the Odoo commit and file digest it was taken from. It cannot detect upstream
  drift.
